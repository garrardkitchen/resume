# Resume site redesign concepts

Open `index.html` to compare all three directions. These are intentionally standalone mockups: they do not change the current Hugo theme, content, or generated site.

## Shared content strategy

All three concepts use the same hierarchy so the visual choice does not obscure the editorial decision:

1. Establish Garrard's role and value in one screen.
2. Give senior-level proof immediately.
3. Show three selected pieces of work as problem, contribution, and outcome.
4. Connect infrastructure, application development, security, delivery, and leadership.
5. Surface open-source tools, writing, speaking, and the full résumé as evidence—not as competing homepages.
6. End with one clear invitation to start a conversation.

The full implementation should keep the exhaustive skills inventory available for search and technical validation, but move it away from the primary narrative. Older projects should be consolidated into a smaller archive. No numerical impact has been invented in these concepts; verified metrics can be added during the content rewrite.

## Concept 01 — Northstar

A bright, calm Azure-inspired editorial design. It feels established and executive without becoming corporate. The portrait and concise proof bar make the person and seniority immediately clear.

Best fit: technical leadership roles, enterprise architecture, principal/distinguished engineering, executive audiences.

## Concept 02 — Control Plane

A dark, system-oriented design that makes architecture, hands-on engineering, and developer tooling the centre of the experience. It borrows visual language from topology maps and engineering consoles without imitating a terminal.

Best fit: platform engineering, cloud-native architecture, principal engineering, open-source and developer-tool audiences.

## Concept 03 — Greenline

A warmer, more human direction built around business outcomes and Garrard's Secure by Design, Cloud First, and Green by Design principles. Sustainability becomes a credible differentiator rather than a side topic.

Best fit: consulting, transformation leadership, client-facing architecture, sustainability-conscious organisations.

## Recommended information architecture for the full build

- Home — positioning, proof, selected work, current focus, call to action
- Work — 3–5 outcome-led case studies plus a compact archive
- Tools — the six current developer tools, with documentation and source links
- Writing — development, architecture, security, AI/MCP, and sustainability
- About — leadership profile, principles, speaking, recognition, and personal note
- Résumé — readable web résumé, downloadable PDF, certifications, detailed skills
- Contact — email, LinkedIn, GitHub, and explicit collaboration interests
