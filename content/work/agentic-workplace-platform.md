## The problem

Agentic AI introduces a new set of interactions between models, tools, enterprise data and user identity. A compelling prototype is not enough: the solution also needs traceable boundaries, safe tool access and a platform that teams can operate.

## My contribution

As technical lead, I worked from architecture through hands-on development. I brought together AI agents, MCP servers and cloud-native application patterns with Azure identity, security and governance. Aspire and Dapr supported a coherent developer and runtime experience across the system.

## The outcome

The work created a practical route from AI experimentation to controlled delivery. Application behaviour, platform capability and security decisions were considered as one system, helping the team make clearer implementation choices.
